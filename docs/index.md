# Bytegeist Documentation

This is the global documentation portal for the Bytegeist system. It summarizes cross-repository architecture and links to generated copies of canonical repository documentation.

## Source of truth

- **Linear** owns work, tickets, ideas, and status.
- **GitHub application repositories** own application code, repository-specific docs, pull requests, and CI/CD.
- **infra-configs** owns infrastructure desired state and operational documentation.
- **bytegeist-docs** owns global and cross-repository documentation.
- **cka-lab** owns learning, labs, notes, and QA.
- **Forgejo** is a mirror/recovery Git service only.
- **Hermes/Larry** is the conversational interface and orchestrator.

The imported repository pages in this site are generated build input. Edit the canonical source repository, not the generated copy.
